# Logion

Open-source, agent-native developer surface for the Logion marketplace.

This repository hosts the public packages that external contributors can work on
without access to the private API repository:

- `packages/cli` — the Logion CLI
- `packages/landing` — the public landing application

The private marketplace backend lives in the separate `logion-private`
repository. Internal teams can coordinate both repos through the private
`logion-workspace` super-repo.
