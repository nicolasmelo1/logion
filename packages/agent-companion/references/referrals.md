# Referrals

Referral commands will be available after the referral program launches.

Planned surface:
- `logion referrals code` — show your referral code
- `logion referrals link COURSE_ID` — generate a referral link for a course
- `logion referrals stats` — show referral statistics
- `logion referrals attributions` — list referral attributions

Safety: always show the course and referral code/link before sharing. Never share referral links without explicit user approval.
