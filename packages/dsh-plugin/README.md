# Logion dsh plugin

This package is a thin DeepSeek Harness profile bundle. It delegates commands
through the locally configured `logion` executable and does not contain a
second API client or credential store.

The package follows the pinned dsh release's `dsh.bundle.patch` entry shape.
The current public release pin is `@deepseek-ai/dsh@0.1.0-rc.6` with npm
integrity `sha512-brpZfED7ieRa2PQ5tUxMhHrM1pb2CmKFVM/f6yMULBDMicahk+Z2OsHgTwTDnoiZm23Ftu9rQz0NN4pflaoJcg==`.
